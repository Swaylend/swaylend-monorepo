## Instructions

1. Use `https://www.rapidtables.com/convert/number/ascii-to-hex.html` to convert the Symbol (e.g. ETH) to hex.

Use the following settings:

- From: Text
- To: Hexadecimal
- Input: `<symbol>` (e.g. ETH)
- Charecter encoding: ASCII
- Output delimiter string: None
- Output: `<hex>` (e.g. 455448) which needs to be prefixed with `0x`
